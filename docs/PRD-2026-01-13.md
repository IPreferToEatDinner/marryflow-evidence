## 1. 产品概述

### 1.1 产品定位

MarryFlow 是一款面向备婚人群的**专业项目管理工具**，通过结构化与可视化的方式，解决传统备婚过程中的核心痛点：

| 痛点 | 解决方案 |
|------|----------|
| 信息零散 | 统一管理任务、预算、供应商、文件 |
| 预算超支 | 实时监控收支，智能预警 |
| 沟通低效 | 多方协作与角色分工明确 |
| 规划复杂 | 阶段化模板与智能引导 |

### 1.2 目标用户

| 用户类型 | 角色定位 | 核心关注点 |
|----------|----------|------------|
| **核心筹备者** | 新郎/新娘（总负责人） | 整体进度、预算控制、最终效果 |
| **执行协作者** | 伴郎伴娘/亲友团 | 具体分工、流程细节、协作通知 |
| **外部合作伙伴** | 策划师/供应商 | 需求对接、合同履约、权限受限 |

### 1.3 适用场景

- **时间跨度**：婚礼前 3-12 个月 → 婚后复盘（约 1 个月）
- **婚礼类型**：中式、西式、目的地婚礼等（支持模板配置）

### 1.4 核心目标

1. **降低复杂度** - 将庞杂事务结构化为清晰任务流
2. **可视化进度** - Dashboard 直观展示筹备状态
3. **控制预算** - 实时监控，避免超支
4. **协同分工** - 明确责权，减少沟通损耗

## 2. 信息架构与页面布局

### 2.1 设计原则

> **"全局概览优先，细节按需展开"**

优先保障桌面端（Web）体验，兼顾平板与移动端适配。

### 2.2 布局结构

```
┌─────────────────────────────────────────────────────────────┐
│                    顶部总览卡片 (Key Metrics)                 │
├──────────┬────────────────────────────────┬─────────────────┤
│          │                                │                 │
│  主导航   │         主工作区                │  活动流         │
│  模块    │      (核心交互区域)              │ (Activity      │
│          │                                │  Stream)       │
│          │                                │                 │
├──────────┴────────────────────────────────┴─────────────────┤
│                       全局工具栏                              │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 模块说明

| 模块 | 功能描述 |
|------|----------|
| **顶部总览卡片** | 距婚期天数、总体进度、预算使用率、今日/逾期任务、高风险预警 |
| **主导航** | 节奏规划、预算管理、人员/角色、供应商库、清单与任务、日程日历、文件中心、通知协作、系统设置 |
| **主工作区** | 核心交互区域，支持看板/表格/日历等视图切换 |
| **活动流** | 实时协作动态（评论、状态变更、文件上传），支持快速回复 |
| **全局工具栏** | 关键词搜索、快速添加（+ 任务/记账/日程） |

### 2.4 响应式适配

| 设备类型 | 断点宽度 | 适配策略 |
|----------|----------|----------|
| 大屏桌面 | ≥ 1440px | 完整展开侧边栏与活动流，多列卡片布局 |
| 标准桌面/横屏平板 | ≥ 1024px | 活动流收起为悬浮抽屉，主内容自适应 |
| 竖屏平板 | ≥ 768px | 导航折叠为图标栏，顶部卡片轮播/堆叠 |
| 移动端 | < 768px | 底部导航栏，卡片单列流式，表格转卡片视图 |

## 3. 节奏规划与进度跟踪

### 3.1 阶段化模型

通过标准化 **"阶段模型"** 将复杂备婚过程拆解为可管理的里程碑：

| 阶段 | 时间范围 | 核心里程碑 |
|------|----------|------------|
| **预备阶段** | M-12 ~ M-9 | 确定婚期、预估宾客人数、设定预算总额、确定婚礼风格 |
| **方案阶段** | M-8 ~ M-4 | 预定场地、签约四大金刚（摄影/摄像/司仪/化妆）、选定婚纱礼服 |
| **执行阶段** | M-3 ~ M-1 | 发出请柬、确定流程表、采购物资、试妆试纱、婚礼彩排 |
| **收尾阶段** | M-0 ~ M+1 | 婚礼当天执行、尾款结算、归还租赁、感谢卡、复盘总结 |

> **注**：M 表示婚礼月，M-3 即婚礼前 3 个月

### 3.2 智能逻辑

| 功能 | 说明 |
|------|------|
| **自定义配置** | 支持新增/删除阶段，修改里程碑时间点 |
| **进度计算** | `总体进度 = Σ(里程碑权重 × 完成状态) / 总权重` |
| **风险预警** | 超期未完成或预算超支 >10% 时触发红色警报 |

## 4. 预算管理

### 4.1 预算规划

| 功能 | 说明 |
|------|------|
| **总额与缓冲** | 设置硬性总预算，建议预留 10%-15% 应急缓冲金 |
| **科目分类** | 一级分类：场地、餐饮、服务团队、服饰造型、布置、交通住宿、其他；支持二级自定义 |
| **多币种** | 支持海外婚礼的多币种记录与汇率换算 |

### 4.2 执行与监控

| 功能 | 说明 |
|------|------|
| **支出记录** | 关联报价单、合同、定金、进度款、尾款；支持上传凭证附件 |
| **现金流时间线** | 基于合同付款节点生成"未来付款日历" |
| **情景模拟** | 超支后的替代方案计算器 |

### 4.3 核心数据字段

```
科目名称 | 预算金额 | 实际支出 | 已付金额 | 待付金额 | 支付对象 | 支付日期 | 状态
```

> 支持 Excel/CSV 格式导入导出

## 5. 人员与角色管理

### 5.1 角色权限 (RACI 模型)

| 角色类型 | 典型成员 | 系统权限 | RACI 职责 |
|----------|----------|----------|-----------|
| **管理员** | 新人 | 最高权限，可配置预算、删改所有数据 | Accountable（负责） |
| **编辑者** | 策划、核心家属 | 可编辑任务、上传文件，不可修改预算上限 | Responsible（执行） |
| **协作者** | 伴郎伴娘 | 仅查看被指派任务，提交完成状态 | Consulted（咨询） |
| **访客** | 供应商 | 受限访问（查看时间表/上传合同） | Informed（知情） |

### 5.2 宾客名单管理

提供独立宾客数据库，支持通讯录导入：

| 字段 | 说明 |
|------|------|
| 基础信息 | 姓名、关系（男方/女方/共同） |
| 邀请状态 | 待发 → 已发 → 已确认/婉拒 |
| 特殊需求 | 饮食禁忌、席位安排、伴手礼记录 |
| 隐私设置 | 支持脱敏展示 |

## 6. 任务与清单管理

### 6.1 任务属性

| 类型 | 属性 |
|------|------|
| **基础属性** | 标题、描述、截止日期、优先级 (P0-P3) |
| **关联属性** | 关联里程碑、预算科目、负责供应商 |
| **逻辑属性** | 依赖关系（如"定婚期"必须在"定酒店"之前） |

### 6.2 多视图支持

| 视图 | 适用场景 |
|------|----------|
| **看板视图 (Kanban)** | 按状态流转：待办 → 进行中 → 阻塞 → 完成 |
| **甘特图 (Gantt)** | 展示时间跨度与依赖关系 |
| **日历视图** | 按日期分布任务 |
| **列表视图** | 批量操作：批量指派、批量延期 |

### 6.3 内置模板库

- 证件办理清单
- 试妆试纱注意事项
- 婚礼当日流程表 (Run-of-Show)
- 应急包清单

## 8. 供应商管理

### 8.1 全生命周期管理

| 管理维度 | 功能描述 |
|----------|----------|
| **档案管理** | 按类别建立档案（场地/摄影/司仪等），记录联系人、联系方式、档期 |
| **报价比对** | 横向对比价格、套餐内容、案例链接、用户评价 |
| **合同履约** | 上传合同，提取付款节点与交付物，标记履约状态 |
| **评价体系** | 黑白名单备注，记录沟通体验与交付质量 |

### 8.2 供应商分类

- 场地（酒店/户外/目的地）
- 四大金刚（摄影/摄像/司仪/化妆）
- 婚纱礼服
- 婚庆布置
- 餐饮/蛋糕
- 花艺
- 交通/住宿
- 其他

## 9. 协作、文件与通用设置

### 9.1 协作与通知

| 功能 | 说明 |
|------|------|
| **消息节流** | 聚合通知避免轰炸，支持"勿扰模式" |
| **上下文协作** | 任务/文件旁直接评论与 @提及 |
| **变更记录** | 关键信息修改保留版本历史，可回溯 |

### 9.2 文件中心

| 功能 | 说明 |
|------|------|
| **统一存储** | 合同、发票、设计图、样片 |
| **智能检索** | 标签分类 + OCR 检索（迭代规划） |
| **格式支持** | PDF、图片、Office 文档 |

### 9.3 系统设置

| 设置项 | 说明 |
|--------|------|
| **本地化** | 语言切换、地区习俗模板（中式/西式） |
| **隐私合规** | 数据最小化收集，敏感数据加密，支持数据导出与销毁 |
| **账户管理** | 个人信息、密码修改、第三方账号绑定 |

## 10. 实施计划与成功指标

### 10.1 版本路线图

| 阶段 | 版本 | 核心功能 | 预计时间 |
|------|------|----------|----------|
| **Phase 1** | MVP | Dashboard 总览、基础任务管理、预算录入统计、人员指派、日历视图、文件上传、通知中心 | - |
| **Phase 2** | v1.0 | 现金流时间线、预算情景模拟、任务依赖与冲突检测、外部日历同步、黑白名单 | - |
| **Phase 3** | v1.1 | OCR 合同/发票识别、权限细粒度控制、移动端原生适配 | - |

### 10.2 成功指标 (KPIs)

**效率与质量**

| 指标 | 目标值 |
|------|--------|
| 任务准时率 | 逾期任务 < 15% |
| 预算偏差度 | 实际支出偏差 ±10% 以内 |
| 风险响应时长 | 高风险事件处理 < 24h |

**用户与协作**

| 指标 | 目标值 |
|------|--------|
| 协作活跃度 | 每项目评论/指派 > 50 次 |
| 用户满意度 | NPS > 40，CSAT > 4.5/5 |
| 月活留存率 | 备婚期内 > 80% |

## 12. 术语表

| 术语 | 说明 |
|------|------|
| **四大金刚** | 婚礼行业对摄影师、摄像师、司仪、化妆师的统称 |
| **Run-of-Show** | 婚礼当日详细流程表，精确到分钟级别 |
| **RACI 模型** | 职责分配矩阵：Responsible（执行）、Accountable（负责）、Consulted（咨询）、Informed（知情） |
| **M-X** | 婚礼倒计时，M 表示婚礼月，M-3 即婚礼前 3 个月 |
| **应急缓冲金** | 预留用于应对突发情况的备用资金，建议占总预算 10%-15% |
| **NPS** | 净推荐值 (Net Promoter Score)，衡量用户推荐意愿 |
| **CSAT** | 客户满意度评分 (Customer Satisfaction Score) |
